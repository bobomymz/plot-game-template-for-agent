# 会话日志 2026-10-21-01 · 引擎起步包

## 做了什么

用户把《九三〇来宾须知》的 engine.js 复制进母本，提议以其范式（引擎底层 / 剧情数据 / 样式 / 装配四分工）为模板标准。经四轮设计确认后全量落地（ADR-0010，workflow-v3.0）：

1. **预置深度**：可跑起步包（用户拍板 A）——不是纯文档定范式，也非引擎原样当参考附件。
2. **schema 权威**：引擎方言为准（用户拍板）。摸底发现文档旧 schema（节点级 `next`、`effects {delta/set}`）从未跑过真实引擎——引擎根本不消费 `next`，旧 dialect 直接落地会开屏即剧终。
3. **去项目化**：软隔离（用户拍板）——引擎逻辑一字不动，仅四处字符串级手术：文件头注释、`_meta` 文案覆盖口（存档弹窗/死亡重开/回溯默认文案/saveSummary）、存档键按页面路径隔离。930 专属机制（睡眠条/手册/闪色/QTE/屏幕特效）不进母本 story/、不挂 DOM 即不激活。
4. **实施**（本次会话全量落地，用户拍板）：
   - `/story/`《雨夜旅馆》迷你演示：新方言活教材（文件头结构图/伏笔标注/选择影响注释三规范齐备，演示 choices 推进/L0 风味/condition 隐藏/elseScene 惯例注释/onEnter 直改与声明式 add/{trust} 插值/redirect 函数）。
   - `index.html` 通用版（可选挂载点注释）、`style.css` 原样带头注、validate.js 以 930 版为底适配（redirect 函数体节点字面量计入静态可达 + 双层一致性检查），fixtures/mini 同步重写。
   - 文档：templates.md §6/§7/§8 重写 + §9 更新 + 新增 §14 引擎速查；CLAUDE.md 五处（145 行保持预算）；叙事路径.md 三处措辞；workflow-guide.html 全面同步。

## 验证

- `validate.js` 跑 /story/ 与 fixtures/mini：全绿（1 提示为设计内——动态路由人工确认）。
- 反向用例：死链/缺表/孤岛、双层 init 不一致，均被抓到（exit 1）。
- Chrome 实测 file:// 双击：真相线（插值/redirect/结局）、死亡线（deathRestart/中性回溯文案/重开回流 start）、存档弹窗（_meta 文案、新存档键、930 旧档不再串入）、未读字条时叩门隐藏。console 无游戏错误。

## 发现的引擎移植性 bug（已在母本修复，930 侧未动）

- 存档键固定 `jiusailing_save_v1`：file:// 同源共享 localStorage，跨游戏串档（实测 930 旧档泄入模板演示）。母本默认按路径隔离，930 沿用旧档需设 `_meta.saveKey`。
