# ADR-0002 阶段 1 概念设计采用「真相先行」固定层序

状态：accepted
日期：2026-10-04

背景：
多项目协作反馈：题材大致确定后 agent 即追问「核心玩法」「需要哪些系统」，设计的轻重缓急错位——规则怪谈未定案件全貌就谈规则玩法，丧尸题材未定爆发真相就谈变种与线索系统，机制与背景脱钩。根源之一是模板阶段 1 的首批提问清单把「需要哪些系统」与题材基调并列。

决策：
阶段 1 概念设计改为固定层序：定调 → 真相 → 谜面 → 机制 → 系统 → 结局。真相 = 作者视角的完整故事因果链，先冻结；谜面、机制、系统、结局逐层由真相派生，支柱/系统/结局均须标注派生来源；真相冻结前 agent 不得提出玩法/机制/系统类问题；每层 3 方案的自评维度随层变化。详见 templates.md §11-§12。

备选方案：
- 维持平铺提问清单（v2.4 现状）：已被实践证伪，机制与背景脱钩，揭谜阶段机制无处落地。
- 仅重排清单顺序、不加层结构与门禁：无冻结约束，agent 仍会跳跃提问。
- 按题材分别写提问剧本（规则怪谈先问案件、丧尸先问成因）：题材不可枚举，且与 ADR-0001 去题材化冲突；故抽象为跨题材的层序 + 题材对照表。

后果：
概念阶段前期变慢、后期返工减少（真相层改动牵动全部下游）；阶段 6 迭代新增内容同样先过真相层；用户先给玩法点子时按「反推真相」处理而非顺流扩写。
