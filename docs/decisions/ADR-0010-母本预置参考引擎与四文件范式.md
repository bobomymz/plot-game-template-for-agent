# ADR-0010 母本预置参考引擎与四文件范式

状态：accepted
日期：2026-10-21

背景：
模板此前的技术形态停在纸面：§8 规定 `/src/engine|ui|save|main/` 四目录自研引擎，节点 schema（`choices[].next`、`effects {delta/set}`、节点级 `conditions`）从未在真实引擎上跑过。《九三〇来宾须知》打完了整部游戏，验证了另一套范式：根目录 `engine.js`（2032 行实战引擎）+ `index.html`（装配）+ `style.css` + `story/` 目录（引导 00core + 按幕分文件 + 三表），零构建、file:// 双击即开。用户把该引擎复制进母本，提议以这套范式为模板标准。

决策：
1. 母本预置「可跑起步包」：根目录 `engine.js` / `index.html` / `style.css` + `story/` 迷你演示游戏（《雨夜旅馆》，双击即玩）。新项目阶段 4 不再自研引擎，改为裁剪与换肤；阶段 3 从「设计引擎/数据模型」改为「定制母本引擎：可选机制挂载、项目专属元字段、存档键与版本」。
2. schema 以引擎方言为准（文档向引擎对齐，不重构引擎）：推进一律 `choices[].nextScene`（单选项＝推进、多选项同目标＝L0 风味；无 choices 即终点，引擎不消费节点级 `next`）；条件三态（对象/表达式串/函数）；`showCondition` 隐藏门槛、`condition`+`elseScene` 显示分流、`condition` 无 `elseScene` 等效隐藏；效果为 `onEnter`（函数直改或 `{set/add/mul}` 对象）与 `choice.effect`；`nextScene` 可为 redirect 函数（返回节点 ID，须有静态兜底）；`text` 支持 `{变量}` 插值与 `para()` 拼段。
3. 变量双层：运行时初值在 `storyData._variables`（00core），闭环对账在 `VARIABLES` 富表（changes 记节点列表）——机器可查降为登记对账，写作纪律由「选择影响」行内注释兜底。
4. 引擎去项目化用软隔离：引擎逻辑一字不动，只做字符串级手术——`storyData._meta` 覆盖口（存档弹窗 title/按钮、死亡重开与回溯默认文案、saveSummary）与存档键默认按页面路径隔离（原固定键 `jiusailing_save_v1` 在 file:// 同源下会跨游戏串档，属移植性 bug）。930 专属机制（记忆闪色/QTE/屏幕特效/手册面板/HUD）不进母本 story/，不挂 DOM 即不激活，挂载模式写进 templates.md「引擎接口与可选机制」。
5. validate.js 以 930 实战版为底（加载顺序排序、沙箱辅助函数桩、requirements/priority 校验），并适配方言：redirect 函数体内引用的已定义节点 ID 字面量计入静态可达，仍计动态提示人工确认。fixtures/mini 与根 story/ 同为《雨夜旅馆》新方言副本——新项目清空 /story/ 后它仍是冒烟基准。

备选方案：
- 纯文档定范式（engine.js 挪 docs/ 作附件）：省事但文档与实物必然漂移，且每项目仍要自研引擎，被否。
- 文档 schema 为准、重构引擎迁就：文档 schema 是未跑过项目的子集（无 onEnter/elseScene/redirect/插值），重构 2032 行实战代码回归风险高，绕一圈仍要扩成引擎方言，被否。
- 硬剥离可选机制（QTE/闪色/屏幕特效拆出模块）：动实战代码且拆出的模块在母本中无使用场景无法验证，被否。
- 索引/对账保持声明式 effects 静态解析：引擎没有该字段；强加等于又造一层纸面 schema，被否。

后果：
CLAUDE.md §2 硬规则 1、§3 阶段 3/4、§7 常用命令、§8 文件树改平铺范式；templates.md §6/§7/§8 按引擎方言重写、§9 初始化清单保留起步包、新增「引擎接口与可选机制」节。母本引擎自此与 930 引擎分叉：仅有的四处手术（文件头、_meta 三处、存档键）集中且有注释，930 侧引擎修复需手动同步回母本（反之亦然）。已知能力缺口：引擎无成就系统，阶段 3 按项目决定 story 层补或裁需求。跨 file:// 页面的 localStorage 串档问题已由路径键根治，但同目录多版本游戏（如 index.html 与 index-test.html）仍会共档，用 `_meta.saveKey` 区分。
