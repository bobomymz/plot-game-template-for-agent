# ADR-0001 工作流文档与游戏题材解耦

状态：accepted
日期：2026-10-04

背景：CLAUDE.md 标题与示例、00-project-state.md 中残留具体题材（鬼吹灯·精绝古城），而仓库文件夹名（恐怖陌生人）为早前 AI 修改的残留，两者不一致暴露出工作流文档与具体项目耦合。用户需要本套文档复用于多个剧情游戏项目。

决策：删除全部具体题材表述，示例改用通用占位（char_xx / loc_xx）；本仓库定位为可复用工作流模板母本，新游戏项目复制整套文档（CLAUDE.md + /docs 结构）后独立演进；不重命名现有文件夹。

备选方案：
- 重命名文件夹并保持单项目专用——否决：用户明确要求可复用。
- 保留题材表述、另建一套模板仓库——否决：两套并行维护成本更高，且耦合问题依旧。

后果：00-project-state.md 在每个复用项目中按项目重置；工作流演进（如 v2.2）继续在本仓库进行并记 CHANGELOG；模板不含任何游戏设定，阶段 1 从零向用户提问。
