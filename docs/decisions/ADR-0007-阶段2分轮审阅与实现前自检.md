# ADR-0007 阶段 2 分轮审阅，实现前先自检文档

状态：accepted
日期：2026-10-05

背景：
骨架先行（workflow-v2.9）把整张骨架交给用户一次审完。建平930 的蓝图在公共脊柱尚未铺开时，已经叠了终幕逻辑、夜的物理、实体走位与整表规则；NPC、机制、地点缠在同一场遭遇里，按种类拆文档会让一次返工改三处。用户要求：审阅包缩小到一轮一问，返工只看差异；正式实现前由 agent 通读全部文档，矛盾与重复清完才许开工，不通过即返工。

决策：
1. 阶段 2 审阅改为四轮（节拍条 → 职责表 → 遭遇卡 → 装配核对），流程写在 `docs/templates/叙事路径.md` §6.1。三路径共用，路径差异只改节拍条的对象。返工按层重开，只出示三行差异。
2. 落地剧情文件前、以及阶段 4 写引擎或扩写正文前，执行 §6.2 文档自检：通读现有全部文档；冻结文档优先于草案可机械消解的矛盾由 agent 改草案，其余出冲突表并停下；重复表述收成单一主文件。冲突表非空不得开始实现。产出记入当次会话日志。

备选方案：
- 继续一次审完整骨架：信息量绑在同一次阅读里，被否。
- 按 NPC / 机制 / 地区拆成独立文档再分别审：三者本是同一场遭遇，拆开后改一处要同步三份，被否。

后果：
CLAUDE.md 只加指针（阶段 2 两行、阶段 4 顺序前置自检、门禁补一条）。审阅与自检的操作细则单写在叙事路径.md §6；实例裁剪时 §6 保留（templates.md §9 第 6 条）。
